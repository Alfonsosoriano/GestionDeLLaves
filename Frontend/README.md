# Frontend - Gestión de Llaves

Este es el frontend de la aplicación de Gestión de Llaves, desarrollado con React y Vite.

## Tecnologías Utilizadas

- **React**: Biblioteca principal para la interfaz de usuario.
- **Vite**: Herramienta de construcción rápida.
- **Sass**: Preprocesador CSS para estilos avanzados.
- **Axios**: Cliente HTTP para peticiones a la API.
- **React Router**: Gestión de rutas.

## Instalación y Uso

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Ejecutar en desarrollo:
   ```bash
   npm run dev
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```

## Estructura del Proyecto

- `src/principal.jsx`: Punto de entrada.
- `src/Aplicacion.jsx`: Definición de rutas y contextos.
- `src/paginas/`: Componentes de página.
- `src/servicios/`: Lógica de comunicación con el backend.
- `src/contexto/`: Proveedores de estado global.
- `estilos/`: Variables y mixins globales de Sass.
